# 知识索引技能

## 知识库结构

```
knowledge/
├── sources.yaml              # 来源可信度白名单
├── macro/                    # 宏观经济知识
│   ├── INDEX.md              #   知识条目索引（从 entries.json 渲染）
│   └── entries/              #   单条知识文件 + entries.json
├── industry/                 # 行业知识
│   ├── INDEX.md              #   知识条目索引（从 entries.json 渲染）
│   └── entries/
│       ├── entries.json      #     程序化条目主索引
│       └── {行业名}/          #     按行业分子目录（如 旅游/）
└── company/                  # 公司知识
    ├── INDEX.md              #   知识条目索引（从 entries.json 渲染）
    ├── entries/              #   单条知识文件 + entries.json
    └── raw/                  #   原始资料存档（年报PDF + 财务CSV）
        ├── index.json         #     程序化检索主索引
        └── {代码}-{公司名}/   #     按公司分子目录
```

- **macro / industry**：知识条目自包含来源和 URL，不设独立 raw/ 目录
- **company**：年报 PDF 和财务 CSV 存入 `raw/{代码}-{公司名}/`，索引维护在 `raw/index.json`
- **INDEX.md** 从 `entries.json` 自动渲染，勿手动编辑表格

## 来源可信度评估

> 完整白名单见 `knowledge/sources.yaml`。

| 等级 | 类别 | 默认可信度 | 示例 |
|------|------|-----------|------|
| L1 | 官方一手数据 | 高 | 央行、国家统计局、SEC、交易所 |
| L2 | 国际权威机构 | 高 | IMF, World Bank, BIS, WTO, UNWTO |
| L3 | 顶级投行 | 中高 | Goldman Sachs, Morgan Stanley, JPMorgan |
| L4 | 国内头部券商 | 中 | 中金、中信、华泰、国泰君安 |
| L5 | 中小研究机构 | 中低 | 区域性券商、小型独立研究机构 |
| L6 | 财经媒体/数据平台 | 低 | Bloomberg, Reuters, AKShare, Wind |
| L7 | 自媒体/论坛 | 低 | 仅作线索参考，不作为知识依据 |

**综合可信度标注**：`高`(L1-L2+多源一致) / `中高`(L3+可追溯) / `中`(L4+部分不确定) / `中低`(L5或以上有疑虑) / `低`(L6-L7) / `待验证`(单一来源)

**采信规则**：L1-L2可独立支撑宏观判断；L3-L4可用作行业/公司参考但需考虑利益冲突；L5及以下不能独立支撑投资判断；单一来源须标注"需进一步验证"；数据不一致时优先采信L1。

### 来源语言多样性

评估来源可信度时，同时关注语言的覆盖：

- 同一个知识主题，优先同时入库中文和英文来源
- 英文来源的搜索通过 `search-online` 技能执行，使用 `search_lang=en`
- 宏观和行业层条目，至少需包含一条英文来源
- 对于信息丰富的领域（宏观政策、行业竞争格局），英文来源不足 1 条 → 条目标记为"待补充英文来源"
- 创建条目时在元数据中标注 `来源语言` 字段

## 新建知识条目

### 文件命名

- **公司**：`entries/{代码}-{公司名}-{主题}.md`
- **行业**：`entries/{行业名}/YYYY-MM-DD_[主题].md`
- **宏观**：`entries/YYYY-MM-DD_[主题].md`

### 条目模板

```markdown
# [主题标题]

**日期**: YYYY-MM-DD
**标签**: `标签1`, `标签2`
**来源**: [来源名称](URL)
**来源资质**: L1-L7
**可信度**: 高 / 中高 / 中 / 中低 / 低 / 待验证
**可信度评估说明**: （1-3句说明评级理由）
**来源语言**: 中文 / 英文 / 中英双语

---

## 摘要
（3-5句概括，区分事实陈述和观点判断）

## 要点
- 要点1
- 要点2

## 数据与指标
| 指标 | 数值 | 时间 | 数据来源 | 备注 |
|------|------|------|---------|------|

## 对投资的影响
- 影响
- 需跟踪的要点

## 信息来源
- [来源1](URL)
- [来源2](URL)
```

### 标签体系

**宏观**：`GDP` `通胀` `货币政策` `财政政策` `就业` `消费` `旅游` `地缘政治` `全球` `中国`
**行业**：按行业加 `OTA` `景区` `酒店` `免税` `航空` `竞争格局` `市场规模` `政策` `估值`
**公司**：公司名、股票代码
**通用**：`长期趋势` `短期波动` `风险提示` `政策驱动`

### 条目文件存放

- **macro**：直接放入 `entries/`（平铺）
- **industry**：放入 `entries/{行业名}/` 子目录
- **company**：直接放入 `entries/`（平铺，文件名含代码前缀）

## 更新索引

每次新建或更新条目后，修改 `entries/entries.json` 并重新渲染 `INDEX.md`。条目按日期倒序。

### entries.json 字段

**macro**：
```json
{"date": "YYYY-MM-DD", "topic": "标题", "region": "区域", "credibility": "高",
 "source_language": "中文", "file": "文件名.md", "sources": ["URL"], "tags": ["标签"]}
```

**industry**：
```json
{"date": "YYYY-MM-DD", "industry": "行业名", "topic": "标题", "region": "区域",
 "credibility": "高", "source_language": "中文", "file": "{行业名}/文件名.md", "sources": ["URL"], "tags": ["标签"]}
```

**company**：
```json
{"date": "YYYY-MM-DD", "company": "公司名", "code": "股票代码", "industry": "所属行业",
 "topic": "标题", "credibility": "中高", "source_language": "中文", "file": "文件名.md",
 "raw_files": ["raw/600169-太原重工-2025年报.pdf"], "tags": ["标签"]}
```

### INDEX.md 表格列

- **macro**: `| 日期 | 主题 | 区域 | 来源语言 | 可信度 | 文件 | 标签 |`
- **industry**: `| 日期 | 行业 | 主题 | 区域 | 来源语言 | 可信度 | 文件 | 标签 |`
- **company**: `| 日期 | 公司 | 代码 | 行业 | 主题 | 来源语言 | 可信度 | 文件 | 标签 |`

## 数据搜集前校验

1. **查 entries/entries.json** — 确认目标是否已有知识条目，对比覆盖范围
2. **查 raw/index.json（仅 company/）** — 确认年报PDF和财务CSV的年份覆盖
3. **全部存在→跳过 / 部分存在→补足 / 不存在→完整搜集**

校验报告格式：

```
| 层级 | 目标 | 已有 | 缺失 | 操作 |
|------|------|------|------|------|
| company | 600169 太原重工 | 2013-2025年报 | 2010-2012年报 | 补足 |
```

## 知识清理

- 宏观数据 > 3个月 → 标记 `[数据可能过时]`
- 知识条目 > 12个月 → 标记 `[待复核]`
- 已被证伪 → 标记 `[已过时]` 并从 INDEX.md 移除
- 低可信度且长期无交叉验证 → 降级或删除
