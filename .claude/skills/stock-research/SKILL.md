# 股票分析技能

## 核心定位

**本技能负责分析，不负责搜集数据。**

- 负责：基于 `knowledge/` 中已有数据进行财务趋势分析、行业对比、估值研判、投资建议
- 不负责：下载年报 PDF、获取财务数据 CSV、爬取原始信息
- 前置条件：目标公司的基础数据必须已通过 `stock-fetch` 入库

## 触发条件（严格匹配）

用户提出以下**分析类**请求时使用此技能：

- "分析 XX 的财报/财务趋势/投资价值"
- "评估 XX 的估值/竞争力"
- "研判 XX 行业/公司的投资机会"
- "对比 XX 和 YY 的财务表现"
- "XX 公司值不值得投资"
- "帮我看看 XX 的财务状况怎么样" — **仅当数据已入库时，基于已有数据分析**
- 任何涉及判断、评估、预测、建议的公司/行业分析请求

**关键词匹配**：分析、评估、研判、估值、对比、投资价值、前景、值得、判断、趋势、风险

**重要边界**：
- 如果用户请求涉及"获取/搜集/下载/拉取"数据 → 先调用 `stock-fetch`，完成后再回到本技能
- 如果 `knowledge/` 中没有目标公司的数据 → 先告知用户需要搜集数据，调用 `stock-fetch`
- 不要在本技能中混合数据搜集逻辑

## 前置步骤：确认数据就绪

在开始分析之前，检查目标公司的基础数据是否已入库：

1. 查阅 `knowledge/company/entries/entries.json` 确认目标公司是否有知识条目
2. 查阅 `knowledge/company/raw/` 确认原始数据文件是否存在
3. 如果数据缺失 → 告知用户并建议先运行 `stock-fetch` 搜集数据
4. 如果数据就绪 → 读取已有条目和原始数据文件，开始分析

## 分析流程

执行自上而下（Top-Down）的分析，严格按以下顺序。每层分析都必须包含**来源可信度评估**。

### 第 0 层：查阅现有知识库与调研项目

在进行任何搜索之前，先查阅本地知识库和当前调研项目：

1. 读取 `research/[项目]/README.md` — 了解分析范围、进度、核心问题
2. 读取 `knowledge/macro/entries/entries.json` — 了解已有宏观经济知识条目
3. 读取 `knowledge/industry/entries/entries.json` — 了解已有行业知识条目
4. 读取 `knowledge/company/entries/entries.json` — 了解目标公司已有数据
5. 在对应层级的 `INDEX.md` 中搜索相关标签和条目
6. 如有相关条目，读取具体文件，注意其标注的可信度等级

### 第 1 层：宏观经济分析

分析公司所处宏观经济环境：
- 全球/区域 GDP 增长趋势
- 货币政策与利率环境（央行政策、流动性）
- 财政政策与地缘政治
- 通胀、就业、消费等关键指标
- 对目标行业/公司的宏观传导机制

搜索关键词示例：`2026 宏观经济展望 货币政策 [区域]`

**搜索工具选择**：先用 `brave_web_search` 广泛搜索话题，发现高价值长文（如 IMF 报告、央行声明全文）后，用 `brave_llm_context` 对具体页面深度提取。

**可信度要求**：宏观分析优先使用 L1-L2 来源（官方机构、国际组织数据），对投行预测性观点标注"预测"属性。

### 第 2 层：行业分析

分析公司所在行业的竞争格局与发展趋势：
- 行业市场规模、增速、渗透率
- 竞争格局（CR5、龙头份额、新进入者）
- 产业链上下游结构
- 政策监管环境
- 技术变革与创新趋势
- 行业估值水平与历史分位

搜索关键词示例：`[行业名] 行业研报 2026 市场规模 竞争格局`

搜索时先用 `brave_web_search` 广泛搜索发现相关研报和文章，对找到的深度行业研报全文用 `brave_llm_context` 提取详细内容。

### 第 3 层：公司分析

深入分析目标公司（基于 `knowledge/company/` 中已有数据 + 补充搜索）：

- 商业模式与护城河
- 财务数据趋势（营收、利润、利润率、ROE、负债率）— 优先采用审计年报
- 管理层与治理结构
- 近期重大事件（业绩发布、并购、诉讼等）
- 投行评级与目标价 — **必须注明投行名称、评级日期、是否存在承销/做市关系**
- 估值分析（PE、PB、PS 历史分位，DCF 参考）
- 与同行业可比公司横向对比

**可信度要求**：
- 财务数据必须来自公司公告/年报原文（L1），而非媒体二次引用
- 投行评级需考虑利益冲突（该投行是否为公司做市商/承销商？）
- 目标价仅供参考，核心依据是公司的实际财务数据和业务分析

搜索时先用 `brave_web_search` 搜索公司近期新闻、投行评级、重大事件；对于找到的深度研报或关键公告全文，用 `brave_llm_context` 提取详细内容。

### 第 4 层：交叉验证与证据归档

1. **交叉验证**：同一指标是否有多来源印证？正面和负面观点是否都充分收集？用 `brave_web_search` 搜索反面观点和质疑声音。
2. **原始资料归档**：分析过程中新获取的补充资料按 `knowledge-index` 规范入库。高价值长文页面用 `brave_llm_context` 提取全文后归档。
3. **信息缺口识别**：列出因数据不足无法确认的关键假设

### 第 5 层：综合研判

整合以上所有分析，形成投资结论：

- **宏观顺风/逆风** — 基于 L1-L2 来源数据
- **行业景气度判断** — 基于 L3+ 来源 + 多源验证
- **公司竞争优势与风险** — 基于年报 + 行业对比
- **估值水平** — 基于公开市场数据
- **催化剂与风险事件** — 基于公开信息 + 预测
- **综合投资观点** — 区分确定性高与确定性低的部分

## 输出规范

### 调研项目创建

首次分析某个行业/公司时：

1. 在 `research/` 下创建项目目录：`research/[项目名]/`
2. 创建目录结构：`README.md` + `reports/` + `notes/`
3. 在 `README.md` 中填写项目概述、分析范围、核心问题、产出清单
4. 在 `TASKS.md` 中创建对应的任务条目

### 调研报告

将完整分析写入 `research/[项目]/reports/YYYY-MM-DD_[主题].md`：

```markdown
# [主题] 分析报告

**日期**: YYYY-MM-DD

## 核心摘要
- 要点（3-5 条），每条标注可信度

## 宏观环境
[分析内容...]
> 可信度评估：[等级] — [说明]

## 行业分析
[分析内容...]
> 可信度评估：[等级] — [说明]

## 公司分析
[分析内容...]
> 可信度评估：[等级] — [说明]

## 估值与综合观点
### 确定性较高的判断
### 需要进一步验证的假设
### 当前信息缺口

## 信息来源与可信度汇总
| 来源 | 资质等级 | 在报告中的用途 | 可信度 |
```

### 知识回写

分析过程中产生的新知识（补充搜索的资料、同行对比数据等），按 `knowledge-index` 技能规范回写 `knowledge/`。

### 项目收尾

1. 更新 `research/[项目]/README.md` 中的产出清单和进度
2. 在 `TASKS.md` 中更新对应的任务状态
3. 如有新发现的子任务或信息缺口，补充到任务列表中
