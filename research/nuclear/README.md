**创建日期**: 2026-04-28
**状态**: ✅ Phase 2 完成 — 研报已输出

## 研究范围

对核电及上下游产业链进行自上而下的系统性调研，覆盖：
- **下游**：核电运营与工程建设（8家）
- **中游**：核心设备与关键零部件（16家）
- **上游**：原材料与核燃料（5家）
- **前沿**：可控核聚变概念（4家）

共 33 只标的。

## 核心问题

1. AI/数据中心带来的增量电力需求是否足以改变核电投资逻辑？是周期性还是结构性变化？
2. 全球核电复兴周期中，哪些指标验证"加速"、哪些可能是"预期透支"？
3. 核电产业链各环节（上游材料/中游设备/下游运营）的业绩传导时序和弹性如何？
4. 当前核准节奏下，哪些环节已price in高确定性、哪些存在预期差？
5. 核电相对其他基荷电源的竞争优势是否在扩大？
6. 当前估值隐含假设和安全边际如何？

## 核心结论摘要

1. AI/数据中心驱动的电力需求增长是结构性增量，但核电建设周期（5-8年）与数据中心缺电的急迫性之间存在显著时间错配
2. 中国核电的核心投资逻辑是"核准节奏驱动的装机增长"，而非"AI需求驱动的定价弹性"——这与美股核电主题有本质区别
3. 产业链业绩释放遵循"设备商→工程商→运营商"的时序规律
4. 核电的竞争力在于"零碳+24/7稳定"的不可替代性，而非绝对度电成本最低
5. 三条投资主线：(a) 运营商装机增长（确定性最高）；(b) 设备商业绩弹性（弹性最大）；(c) 民企低基数逻辑（空间最大但确定性最低）
