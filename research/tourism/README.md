# 旅游业调研项目

**创建日期**: 2026-04-26
**状态**: 🔄 进行中
**优先级**: P1

## 调研目标

对旅游行业进行自上而下（Top-Down）的系统性调研：宏观经济环境对旅游业的影响 → 旅游行业竞争格局与细分赛道 → 主要上市公司分析。

## 调研范围

### 细分赛道
- 在线旅游（OTA）：携程、同程旅行、美团旅行
- 景区运营：宋城演艺、中青旅、黄山旅游
- 酒店集团：华住、锦江酒店、首旅酒店
- 免税零售：中国中免
- 航空客运：三大航 + 春秋/吉祥

### 核心问题

1. 2026 年旅游行业景气度如何？复苏动力是否持续？
2. 消费降级趋势对旅游消费结构的影响？
3. 各细分赛道的竞争格局和利润率水平？
4. 估值水平是否合理？哪些公司具有安全边际？

## 产出

- [ ] 宏观环境分析 — 消费信心、出行数据、政策环境
- [ ] 行业全景报告 — 市场规模、竞争格局、细分赛道对比
- [ ] 重点公司深度分析（待确定具体标的）
